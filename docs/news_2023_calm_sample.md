재작성 2026-11-13 / 확인 결과 반영 2026-11-15 / 최종 재검토 수정 2차. **본표 21건 + 추가 반례 후보 4건.** 회사 블로그·회사 자체 보도자료는 본표에서 제외했다.

## 1. 선정과 시간 확인

USDC·Circle·스테이블코인의 운용·도입·규제·준비금 공시·사용량 보도 가운데 실제 USDC 페그 위기나 준비금 보관 은행의 지급불능을 제목으로 보도하는 사례가 아닌 것을 본표로 골랐다. 다른 발행사의 일반 소식과 부인된 루머도 포함한다.

원 매체 기사 페이지 또는 보관본을 대조했다. UTC 시각은 15건이 메타데이터의 초·소수초 단위이고 6건은 원문 표시 EST를 변환한 분 단위다. 분 단위 행에 정밀한 초를 확인했다고 표시하지 않는다. 본표는 현재 제목의 오탐 점검 자료이며, 모든 최초 발행 당시 제목을 보증하는 리드타임 입력이 아니다.

본표의 기대 경보는 0으로 제안한다. 이 라벨은 USDC 준비금 위험 탐지 목적에 대한 제안이며 담당자 최종 승인 전이다.

## 4. 실행 결과와 사용 한계

본표 21건에 기준 커밋 8ef6cac의 v2.1 규칙을 수정 없이 적용한 기존 결과는 A/B 0건, 뉴스 플래그 0인 제목 21건이다. #19 규제 의견 기사만 C(관찰)다. 이 문서 수정 과정에서 원 신호 파일을 생성하거나 코드·규칙을 변경하지 않았다.

- 선택한 21건의 결과이며 기간 전체 오탐률 0%를 뜻하지 않는다.
- 같은 사건의 중복 보도 쌍은 #4·5, #7·8, #14·15, #20·21 네 쌍이다. 중복을 묶은 사건군은 17개다. 통계적 독립성이 입증됐다는 뜻은 아니다.
- 이 표로 규칙을 수정하면 이후 성능은 다른 표본으로 평가해야 한다.
- 본표와 추가 후보의 사람 정답 라벨 최종 확인은 담당자 승인 대기다.

- 11/15 수정: 당시 은행 목록의 Silvergate 포함을 명시하고, 후보 네 건의 규칙 참고 결과와 사람 라벨을 분리했다. H3·H4는 기대 경보 0 제안·승인 전으로 통일했다.
